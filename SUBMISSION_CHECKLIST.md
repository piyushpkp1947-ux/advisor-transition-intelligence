# Submission checklist

## Files

- [ ] Plan and Solution Design PDF (≤5 pages)
- [ ] Technical Report PDF (≤10 pages)
- [ ] Client Proposal PDF (≤5 pages)
- [ ] Final Presentation PPTX/PDF (≤12 slides)
- [ ] Source ZIP
- [ ] Dataset CSV plus source registry
- [ ] Results CSV/JSON
- [ ] README
- [ ] `DEPLOYMENT.md` and `DEMO_SCRIPT.md`

## Verification

- [ ] Run `python -m unittest discover -s tests -v`
- [ ] Run `python validate_submission.py`
- [ ] Launch the app from a clean terminal
- [ ] Demonstrate both “retain current” and “transition” outcomes
- [ ] Confirm no PII, `.env`, secrets file, or API keys are in the final ZIP or repository
- [ ] Rehearse the five-minute demo once without editing the app during the presentation

## External actions still required

- [ ] Create/push the GitHub repository, if a public code link is required
- [ ] Deploy the Streamlit app, if organizers need a live URL
- [ ] Confirm deployment visibility and any organizer-specific submission method
